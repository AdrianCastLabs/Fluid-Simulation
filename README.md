# Fluid Simulation
 ### Status: Active development
 A fluid simulation implemented on the Unity Engine.

 I made this project to learn and understand how SPH (Smoothed Particle Hydrodynamic) simulations work

 ## This simulation currently Implements:
 - Pressure force computation
 - Particle collisions
 - Boundary collisions
 - Density visualization

 ## Future Goals
  There's still a lot of features I want to implement such as: 
  - Fluid rendering
  - Surface tension
  - Viscosity
  - Spatial partitioning
  - Accuracy and stability
  - 3D
